# Skill — Reconnaître et soumettre le flag

Signes : une sortie contient un motif `...{...}`.

Étapes :
1. Le format par défaut est `csaw{...}` (insensible à la casse sur `csaw`).
2. Vérifier que le contenu entre accolades est plausible (pas de texte d'erreur).
3. Soumettre immédiatement avec `submit_flag`.

Piège : ne pas confondre un exemple de format donné dans l'énoncé avec le vrai flag.
